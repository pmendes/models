This repository has permanently moved to https://codeberg.org/pmendes/models.

The folder **vonDassow2000**, containing a model and code for the a segment polarity network model of [von Dassow et al. (2000)](https://doi.org/10.1038/35018085) 
as published in
([Mendes 2023, Reproducibility and FAIR principles: the case of a segment polarity network model *Frontiers in Cell and Developmental Biology* 11:1201673](https://doi.org/10.3389/fcell.2023.1201673))
is kept here read-only because it is referenced in a publication 
The data here is also in [Zenodo](https://doi.org/10.5281/zenodo.7772570)
